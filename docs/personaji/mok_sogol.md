# Мок Согол

Смуглый юноша из племени Мок, живущего на равнинах. На лице — ритуальные шрамы. Суровый, практичный охотник, предпочитающий арбалет луку. Не доверяет иррациональному и магическому (например, духам леса).Его фамильный клан выжил благодаря пещере с огненными яйцами драконов. Согол приручил жестокого огненного дрейка (см. Свежеватель).

# Свежеватель

Огненный дрейк (детеныш дракона), фамильяр Мок Согола. Вылупился из яйца, найденного племенем Мок. Отличается крайним садизмом (сожрал собственных братьев и сестер в кладке). Выдыхает жар, чтобы пугать врагов. Питается только свежей плотью на охоте.
